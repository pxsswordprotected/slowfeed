# Slow Feed

A Chrome extension for X (Twitter) that helps restore your attention span.

Slow Feed makes you read your timeline one tweet at a time. The next tweet stays blurred until you've spent a set amount of time on the current one. A thin timer bar on the active tweet shows your progress. No more mindless scrolling.

> **Status: in development.** Things are unfinished, rough, and likely to change or break. Expect bugs, especially when X changes its markup.

## What it does

- Works on the feed screens: Home, Search, Explore, Lists, Communities.
- Leaves single tweets, profiles, notifications, messages, and settings alone.
- Matches X's light, dim, and lights-out themes.
- Runs locally. No backend, no network calls, no analytics.

## Install (unpacked)

1. Clone this repo.
2. Open `chrome://extensions` (also works in Edge and Brave).
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the repo folder.
5. Open [x.com](https://x.com/home) and click the Slow Feed icon in the toolbar to turn it on.
